# V3 GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留 V2 Agent 内核和 CLI 的前提下，交付一个本地 FastAPI + React 工作台，支持多项目、单任务运行、实时事件、审批恢复、Shell/Diff/Trace 可观察性。

**Architecture:** FastAPI/Uvicorn 提供 REST 与原生 WebSocket；React 独立 npm 工程负责 GUI；V2 SessionSnapshot 与 TraceWriter 仍是领域事实来源。Chainlit 只贡献保留 Apache-2.0 声明的展示组件。

**Tech Stack:** Python 3.10+, FastAPI/Uvicorn/Pydantic（后端新增依赖）；React 18、TypeScript、Vite、TanStack Query、Zustand、Tailwind、Radix/shadcn、Vitest、Playwright。
