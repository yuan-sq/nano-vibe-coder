# 双 README 文档 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 编写符合题目 1000 字限制的 `README.txt`，并把现有 `README.md` 扩充为准确、易读的中文项目主页。

**Architecture:** 两份文档共用同一组技术事实，但服务不同读者。`README.txt` 只保留提交必需信息；`README.md` 从项目动机和有限状态机讲起，再给出运行方法、权限边界、工具、架构与验证说明。初稿完成后使用 humanizer-zh 的检查项逐段压缩宣传式语言和模板化表达，不改动命令或技术语义。

**Tech Stack:** 中文纯文本、GitHub Flavored Markdown、uv、Typer CLI、FastAPI、React/Vite
